# RaoDo Dashboard

A React analytics dashboard built as a take-home interview assessment. Displays task/item breakdowns with charts and priority highlights.

## Features

- 📊 Pie chart visualization (Google Charts)
- 🔥 High-priority items view
- ✨ Highlights summary panel
- Material UI component library for layout and styling

## Tech Stack

React 18, Material UI (MUI), react-google-charts, Create React App

## Project Structure

```
src/
  ├── Components/
  │   ├── Dashboard.jsx
  │   ├── Navbar.jsx
  │   ├── Highlights.jsx
  │   ├── HighPriority.jsx
  │   └── Piechart.jsx
  ├── Assets/
  ├── Styles/
  └── App.js
```

## Getting Started

```bash
git clone https://github.com/SaurabhGarg6174/RaoDo-Dashboard.git
cd RaoDo-Dashboard
npm install
npm start
```
